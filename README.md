## 🚀 Projects I've Built

### 📒 [SupBooks](https://github.com/Mukesh-RM/mukesh-supbooks) — GST-Compliant Invoicing System
> **FastAPI · React 19 · Tailwind CSS · SQLite · SQLAlchemy**

A production-grade invoicing and business management system built for an actual Indian SMB (**Eshwar Engineering**). Handles the full business document lifecycle from end to end.

- ✅ Complete **Quotation → Invoice → Payment → Delivery Challan** workflow
- ✅ Automatic **CGST/SGST vs IGST** logic based on buyer-seller state codes
- ✅ Financial-year smart numbering (`INV-2026-27-001`) with configurable prefixes
- ✅ Print-to-PDF A4 templates with logo, stamp, and signature support
- ✅ UUID primary keys, customer snapshots, full Swagger API docs

---

### 📈 [TradesUp](https://github.com/Mukesh-RM/Tradesup) — Options Trading Education Platform
> **React 18 · TypeScript · Tailwind CSS · Vite · React Router**

A specialised education platform for Indian options traders — built for serious learners who want practical, market-specific knowledge beyond generic tutorials.

- ✅ Full SEO pipeline — sitemap.xml, robots.txt, Open Graph, Twitter Cards, structured data
- ✅ Production build deployed on Netlify with redirect handling
- ✅ Clean, responsive UI built with Tailwind + Lucide icons

---

### 🤖 [CURA](https://github.com/Mukesh-RM) — Conversational AI Platform
> **Python · Flask · React.js · Firebase · ElevenLabs · Tailwind CSS**

Real-time conversational AI system with voice/text streaming, modular LLM orchestration, and session memory — built for reliability and predictable responses.

- ✅ Async batching + short-lived caching for multi-turn stability under load
- ✅ Firebase Auth protected API routes with secure session token management
- ✅ **~30% reduction in fallback errors** after usability testing with **50+ users**

---

### 🗺️ [PATHFLOW](https://github.com/Mukesh-RM) — Career Path Recommendation Engine
> **Python · Workflow Automation · REST APIs · Netlify**

Deterministic rule engine that maps student confusion into structured, guided career decision trees.

- ✅ Guided **100+ students** from ambiguity to a clear next step in a few screens
- ✅ **~45% reduction in decision friction** measured post-deployment
- ✅ Modular API components assemble personalised paths based on prerequisites and intent

---

### 📊 [Vocabulary Learning Analytics](https://github.com/Mukesh-RM) — Learning Intelligence System
> **Python · Pandas · SQLite · Power BI / Tableau**

Tracks user learning interactions (accuracy, difficulty, attempt history) and surfaces insights through BI dashboards.

- ✅ SQL + Pandas analysis of learning curves, difficult-word clusters, retention patterns
- ✅ Power BI / Tableau dashboards for performance visualisation and progress tracking
